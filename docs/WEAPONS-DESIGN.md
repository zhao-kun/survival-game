# 武器/护甲品级与技能书系统 —— 需求与设计文档

> 版本：v1.0（设计定稿）　日期：2026-02　状态：**待开发**
> 本文档是武器/护甲大版本的唯一需求与设计来源，开发按第 6 节里程碑推进，每完成一项更新「状态」列。

## 1. 需求清单（FR = Functional Requirement）

| 编号 | 需求 | 来源（用户原话） |
|---|---|---|
| FR-1 | 武器分**近战/远程**两大类 | 近战：刀、锤、棍、枪；远程：弓、弩 |
| FR-2 | 每类武器有**三大材质档**：石质、铁质、钢制 | 「每类武器有三大子类别，石质，铁质，钢制」 |
| FR-3 | 每种材质档下 **6 个级别** | 「每种制作类别下有设置6个级别」 |
| FR-4 | 级间小幅提升、材质间大幅提升 | 「每个级别间的伤害等属性稍有提升…材质提升后…大幅提升」 |
| FR-5 | 每类武器**独特效果** | 刀流血/断头；锤扇形 AOE/震慑；棍击飞/爆头；枪致残/直线穿透；弓速攻/低伤/隐蔽；弩高伤；弓弩流血 |
| FR-6 | 所有武器制作需**技能书解锁**，书打怪掉落，**每 3 本升一级** | 「1级石质物品无需技能书解锁。3本刀书解锁2级石刀，15本解锁6级石刀。18本解锁1级铁刀」 |
| FR-7 | 护甲同步扩品级（石/铁/钢 × 6 级） | 「更多武器/护甲品级与插件加入」 |
| FR-8 | 插件扩充（配合新武器效果） | 「更多武器/护甲品级与插件加入」 |

## 2. 武器分类树与命名

### 2.1 分类树（6 类 × 3 材质 × 6 级 = **108 件武器**）

```
武器
├─ 近战 melee
│   ├─ 刀 knife   —— 快速、流血、断头
│   ├─ 锤 hammer  —— 慢速重击、扇形 AOE、震慑
│   ├─ 棍 club    —— 中速、击飞、爆头
│   └─ 枪 spear   —— 中距、直线穿刺、致残
└─ 远程 ranged
    ├─ 弓 bow     —— 攻速快、伤害较低、隐蔽射击
    └─ 弩 crossbow —— 伤害高、装填慢
```

### 2.2 物品 id 规则与命名

- **武器 id**：`{mat}_{cls}_l{n}`，如 `iron_knife_l3` = 3 级铁刀、`steel_hammer_l6` = 6 级钢锤
- **材质三档**（武器系统独立编码，**不沿用工具的 wood 档**；现有 `wood_*` 工具链不动，存档安全）：

| 内部 id | 中文名 | 颜色 | 伤害倍率 matMul | 制作材料 |
|---|---|---|---|---|
| `stone` | 石质 | 0x9a9a92 灰石 | 1.0 | 圆石 + 木棍 |
| `iron` | 铁质 | 0xc8cdd6 银 | 1.6 | 铁锭 + 木棍 |
| `steel` | 钢制 | 0x7e8fa0 钢青 | 2.5 | 钢锭 + 铁棍 |

- **显示名**：`{材质}{级别}级{武器}`，如「铁3级刀」「钢6级锤」
- **icon**：沿用类 icon（刀🔪 锤🔨 棍🥍 枪🔱 弓🏹 弩🎯），名字里带级别
- ⚠️ **兼容**：现有 `iron_sword`（铁剑）保留为过渡武器不动；新刀从 `stone_knife_l1` 起

### 2.3 护甲（72 件 = 4 部位 × 3 材质 × 6 级）

- **id**：`{mat}_armor_{slot}_l{n}`，slot ∈ `helm 胸甲 chest 护腿 legs 靴子 boots`
- **成套解锁**：护甲**不需要技能书**，但材质是门槛——铁质套需先获得任意铁质武器（材料门槛），钢制套需钢锭
- **护甲值 armor**：`基础值(头2/胸4/腿3/靴1) × matMul × (1 + (lv-1)×0.10)`，四舍五入到 0.1
- **减伤公式**：全身 armor 总和 A → **受伤乘子 = A/(A+30)**（递减收益，A=10 减 25%，A=30 减 50%，A=60 减 67%）
- **接现有 EQUIP_SLOTS**（head/chest/legs/boots 已存在，直接占用）

## 3. 数值设计

### 3.1 伤害公式（FR-4 核心）

```
damage = base × matMul × (1 + (lv − 1) × 0.08)     → 四舍五入到 0.1
```
- **级差**：+8%/级（小幅：石 1→6 级总提升 +40%）
- **材质**：石→铁 +60%、铁→钢 +56%（大幅：钢 6 级 = 石 1 级的 **3.5 倍**）

### 3.2 六类武器基准表

| 类 | base | 攻速 rate(秒/击) | 击退 knock | 射程 | 定位 |
|---|---|---|---|---|---|
| 刀 knife | 12 | 0.50 → 0.36（每级 −0.028） | 0.8 | 2.6 | 高频单点 + 流血 |
| 锤 hammer | 18 | 1.25 → 1.02 | 2.4 | 2.8 | 慢速重击 + AOE |
| 棍 club | 9 | 0.85 → 0.66 | 1.6 | 2.8 | 控制（击飞/爆头） |
| 枪 spear | 14 | 0.90 → 0.72 | 1.0 | 3.6 | 中距直线穿透 |
| 弓 bow | 13 | 1.10 → 0.62（拉弓快） | — | 40 | 高频远程 + 隐蔽 |
| 弩 crossbow | 24 | 1.90 → 1.40 | — | 40 | 高伤狙击 + 流血 |

- **rate 同样按级微调**（−3.5%/级），材质不改变攻速
- **弹药**：弓→arrow、弩→bolt（沿用现有，不新增）

### 3.3 数值示例（刀）

| 级 | 石 | 铁 | 钢 |
|---|---|---|---|
| L1 | 12.0 | 19.2 | 30.0 |
| L3 | 13.9 | 22.3 | 34.8 |
| L6 | 16.8 | 26.9 | 42.0 |

### 3.4 合成配方（每级材料递增）

```
武器 n 级配方 = 基础材料 × (1 + (n−1) × 0.5)   → 数量取整
石质：圆石 n+2 个 + 木棍 2 个；铁质：铁锭 n+1 + 木棍 2；钢制：钢锭 n + 铁棍 1
```
- 全部在**工作台**合成；钢锭配方：铁锭 2 + 煤 1（熔炉）→ **新增**
- 制作耗时：近战 2s + 0.2s×级别；弓弩 3s + 0.3s×级别（接现有制作队列）

## 4. 独特效果机制（FR-5）

### 4.1 状态效果引擎（entities.js 通用化）

在 Zombie/Animal 上加统一状态字段，update 中处理：

| 状态 | 字段 | 效果 | 来源 |
|---|---|---|---|
| 流血 bleed | `bleedT`, `bleedDps` | 每秒掉血，红色粒子 | 刀/弓/弩命中 |
| 震慑 slow | `slowT` | 移速 ×0.5，踉跄动画 | 锤 AOE 概率 |
| 致残 cripple | `crippleT` | 移速 ×0.6，跛行 | 枪命中概率 |
| 眩晕 stun | （已有 stunT） | 硬直 | 棍击飞落地 |

- **同类状态刷新取更强者**（dps 更高 / 时间更长），不叠加

### 4.2 头部判定（headshot）

- 近战：命中时取**玩家准星与怪物头部包围盒的交点高度**——简化：`击中方向 dot(look, 到头部中心) > dot(look, 到身体中心)` 且 `dist < 射程` 判头部
- 远程：投射物命中时 `命中点 y > mob.pos.y + headH`（僵尸 1.45，野猪 0.85）
- **头部伤害 ×1.5**（所有武器通用），再走各类武器特技

### 4.3 六类特技表

| 武器 | 特技 | 触发 | 概率/数值（随级别增强） |
|---|---|---|---|
| **刀** | 流血 | 每次命中 | bleedDps = 2 + 0.4×lv，持续 4s |
| | 断头（即死） | 命中头部 | 8% + 2%×lv（钢6 = 20%）；Boss 免疫 |
| **锤** | 扇形 AOE | 每次挥击 | 主目标 100%，扇内其余 60%；扇形 = 半角 60°、半径 3.5 + 0.1×lv |
| | 震慑 | AOE 命中（含主目标） | 25% + 2%×lv，slowT = 2s |
| **棍** | 击飞 | 每次命中 | knock 1.6 + 垂直 vel.y +3.5（1.5m 抛起），无 AOE |
| | 爆头/暴击 | 命中头部 | 爆头（×3 伤害）15% + 2%×lv；未爆头普通头部 ×1.5 |
| **枪** | 致残 | 每次命中 | 30% + 3%×lv，crippleT = 4s |
| | 直线穿透 | 每次挥击 | 一条线（半角 8°、射程 3.6+0.1×lv）上全部敌人依次受击 70%，最多 3+floor(lv/2) 人 |
| **弓** | 速攻 | 被动 | rate 快（表 3.2），伤害低于弩 |
| | 隐蔽 | 射击后 | 12m 外的怪**不因这次攻击**进入 aggro（潜行狙击） |
| | 流血 | 命中 | bleedDps = 1.5 + 0.3×lv，3s |
| **弩** | 重伤 | 被动 | 伤害最高；bleedDps = 3 + 0.5×lv，5s |

- 弓弩的流血与刀同引擎（4.1），弓弩**无**断头/爆头特技

### 4.4 与插件（FR-8）的叠加

新增 6 种插件（target: weapon），与现有 8 种同框架：

| id | 名称 | 效果 |
|---|---|---|
| mod_bleed | 放血插件 | 流血 dps +25% |
| mod_stun | 震慑插件 | 锤震慑概率 +10% |
| mod_head | 狩猎插件 | 头部特技概率 +6% |
| mod_cripple | 破甲插件 | 致残概率 +12% |
| mod_aoe | 荡涤插件 | 锤扇形半径 +0.6m |
| mod_pierce | 贯穿插件 | 枪穿透人数 +1 |

- 掉落：ZOMBIE_LOOT plugin 池扩充；也可用铁锭合成（工作台）

## 5. 技能书系统（FR-6）

### 5.1 书与熟练度

- **6 种书**：`book_knife 刀谱 / book_hammer 锤谱 / book_club 棍谱 / book_spear 枪谱 / book_bow 弓谱 / book_crossbow 弩谱`（kind: book，stack: 99，不可使用，纯熟练度材料）
- **熟练度**：按类累计**读过的本数**（右键使用即「研读」→ 计数 +1 + loot feed 提示）；存档保存 counts
- **掉落**：ZOMBIE_LOOT 新增条目 `chance 0.07`，随机掉 6 类之一；野猪掉落 0.10 随机一种（猎物也出书）；感知「拾荒」技能加成照常生效

### 5.2 解锁公式（用户规则精确建模）

> 「每 3 本书提升一级；1 级石质免费；3 本刀书解锁 2 级石刀，15 本解锁 6 级石刀；18 本解锁 1 级铁刀」

```
gi      = floor(count / 3)          // 全局级序：0..17
tierIdx = floor(gi / 6)             // 0=石 1=铁 2=钢
lvl     = gi % 6 + 1                // 1..6
```

| 本数 | 解锁 | 本数 | 解锁 | 本数 | 解锁 |
|---|---|---|---|---|---|
| 0–2 | 石 L1（免费） | 18–20 | 铁 L1 | 36–38 | 钢 L1 |
| 3–5 | 石 L2 | 21–23 | 铁 L2 | 39–41 | 钢 L2 |
| 6–8 | 石 L3 | 24–26 | 铁 L3 | 42–44 | 钢 L3 |
| 9–11 | 石 L4 | 27–29 | 铁 L4 | 45–47 | 钢 L4 |
| 12–14 | 石 L5 | 30–32 | 铁 L5 | 48–50 | 钢 L5 |
| 15–17 | 石 L6 | 33–35 | 铁 L6 | **51** | 钢 L6（满级） |

- **每类独立**：刀书只解锁刀；满级一类需 51 本
- **可制作 = 已解锁级别内所有武器**；未解锁配方在工作台**灰色锁定**并提示「需 {n} 本{书名}（还差 {k} 本）」

### 5.3 UI 设计

- **新面板「⚔ 技能」**（K 键打开 + 工作台内 Tab 切换）：6 行 × [类名 | 书计数 ▓▓▓░ | 当前可做最高 {材质}{级} | 下一解锁进度 3/6 本]
- 工作台武器页签按 近战/远程 分组、材质分栏，锁定项灰显 + 悬浮提示差几本书
- 拾取书时 loot feed：`📜 获得刀谱（刀谱 7/51）`

## 7. 兼容性与风险

| 风险 | 对策 |
|---|---|
| 旧存档无新物品/熟练度字段 | 全部新字段缺省安全（counts={}、书 0 本 → 石 L1 可用）；旧 iron_sword 照常 |

| 概率特技测试不稳定 | 测试用注入式（直接调 applyBleed 等）+ 大样本统计（100 次采样断言区间） |
| headless 帧率波动 | 沿用绝对阈值断言惯例 |
| AOE 误伤友军/掉落物 | 只对 zombies+animals 生效，与现有 melee 一致 |
