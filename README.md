# 方块求生 · 僵尸末日

一个网页版体素生存游戏（类我的世界 × 僵尸末日），使用 Three.js + 原生 ES Modules 构建，无需打包工具。

> 📋 全部游戏特性详见 [FEATURES.md](FEATURES.md)。

## 运行方式

游戏需要通过 HTTP 服务访问（ES Module 限制），任选其一：

```bash
cd survival-game
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

或者：`npm start`（等同上面的 python 命令）。

> `lib/three.module.js` 已本地化，离线也可以运行。

## 操作说明

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 空格 | 跳跃 / 游泳上浮（在水面朝岸推进会自动跃出上岸） |
| Shift | 疾跑（消耗更多饥饿） |
| 鼠标左键 | 攻击 / 对准方块按住采集 |
| 鼠标右键 | 放置方块 / 进食饮水 / 穿装备 / 空瓶装水（对选中的物品栏物品） |
| 空手+右键 | 对准水面直接喝生水解急（会拉肚子！） |
| 1-9 / 滚轮 | 切换物品栏 |
| E | 物品栏 & 合成面板 |
| B | 背包 & 装备面板（单击背包物品直接使用；右键与物品栏互移） |
| K | 技能树 |
| H | 帮助 |
| V | 切换第一 / 第三人称 |
| Esc | 关闭面板 / 释放鼠标 |

### 物品栏与背包

- **物品栏**（9 格，屏幕底部常显）：选中后右键即可快捷使用（吃、喝、穿、放方块）
- **背包**（27 格起步，可扩容）：按 **B** 打开；背包里的东西必须打开背包**单击使用**
- **右键**背包物品移入物品栏，右键物品栏物品移回背包；拾取的新物品优先进入物品栏空位

## 玩法循环

1. **采集**：徒手砍树 → 木镐挖石 → 铁镐挖铁矿（石头/矿石需要镐）；**铁矿石 = 地下石头层里橙色斑点的方块**（木镐即可挖，约 3 秒/块，首次挖到有提示）
2. **合成**：手工（木板/木棍/线/篝火/熔炉/工作台/木工具）；**高级物品一律在工作台制作**（多样材料+图纸解锁）：弓=木棍+线+胶水、铁剑=铁锭+木棍+胶水、绷带=布料×2+线、皮甲/铁甲/钢甲全套等
3. **收获提示**：挖到东西/捡到掉落物时，屏幕右下角弹出「icon +n 名称」卡片，约 5 秒后自动消失（采集/击杀僵尸/狩猎猪的收获一目了然）
4. **状态与饮食 buff**：屏幕左下角实时显示所有状态（绿色增益/红色减益）——烤肉=饱食回血 90 秒、炖肉汤=长时间回血+治脑震荡、骨头汤=受伤减免、烤肉串=近战增伤、什锦大餐=超长回血+移速提升，越高级的餐食增益越强
5. **创伤与医疗**：被僵尸攻击可能擦伤（30%）/脑震荡（15%）/断手（10%）——绷带治擦伤、炖肉汤治脑震荡、夹板（木棍×2+布料×2）治断手、医疗包（绷带+夹板+胶水，工作台）治愈一切
3. **建造**：右键放置方块，搭建庇护所（落水后朝岸游即可爬上岸）
4. **生存**：饥饿与口渴持续消耗；猎猪取肉与皮革、篝火烹饪
5. **喝水**：空手对水右键直接喝生水（应急但拉肚子）；空瓶装生水 → 篝火烧成开水（安全）
6. **状态效果**：喝生水会拉肚子——持续掉血、饥饿消耗加倍、无法自然回血，等待自愈
7. **打猎**：猪逃跑速度慢于玩家步行、受击硬直、有喘息期，追上连砍即可；不会跑出地图边缘
8. **烤肉**：手持生肉对准篝火右键直接烤熟；生肉生吃会掉血
9. **新手保护期**：前 3 天没有僵尸（HUD 显示 🛡️），抓紧挖矿/盖房/合成铁装；之后僵尸数量与等级随天数和你的等级装备逐步提升（顶部时间栏可见进度），前期少量低级怪不会碾压
10. **制作耗时**：所有制作都需要时间——背包合成材料秒级、工具数秒、装备十余秒；篝火/熔炉制作见下条
11. **篝火/熔炉制作队列**：对准它们右键打开界面，点击配方即<b>入队</b>（自动扣原料），队列最多 4 个任务位，做完一个自动开始下一个；排队中的任务可随时<b>取消</b>（原料退回）；做好的物品先进<b>产出暂存</b>（最多 6 件）：左键收进背包，食物/饮料可<b>右键直接使用</b>；<b>放燃料</b>：打开容器面板时快捷栏会暂时隐藏；点击面板内「随身物品栏」中带 🔥 标记的物品即放入燃料槽，<b>每次点击放 1 块可叠加</b>（10 块木板 = 600 秒）——1 木板烧 60 秒（原木 120 秒/木棍 15 秒/煤炭 90 秒/<b>木工具 15 秒</b>），<b>木板的制作物都能当柴烧</b>；燃尽自动续烧，燃料耗尽则暂停（不丢进度，补燃料自动继续）；<b>制作与玩家位置解耦</b>——放好队列可以去砍树/打怪/探索，篝火与熔炉各自独立同时工作；<b>队列空火焰不熄</b>——剩余燃烧时间继续保留（不会凭空消失），可点「关火」提前结束（剩余时间保留，下次入队或点火直接复燃续用）
12. **一天 1 小时**：游戏内一天 = 真实 1 小时，日夜缓慢流转；口渴/饥饿按一天约一瓶水/四餐锚定，不用频繁吃喝
13. **存档系统**：开始界面输入（或点选历史）用户 ID，按 ID 保存进度；每 30 秒自动保存（天数/位置/生命/口渴饥饿/经验等级/技能/物品栏/装备/方块改动 diff/篝火熔炉容器状态）；死亡后该 ID 存档清除，重开菜单可换新 ID
14. **玻璃杯水链**：沙子 → 熔炉烧成玻璃 → 玻璃烧成玻璃杯；空杯对准水面右键接生水 → 篝火烧成开水 → 饮用解渴并返还空杯（空瓶同理可循环）
5. **战斗**：夜晚僵尸成群（等级 1-3，掉落武器/弹药/食物/插件）；弓箭与弩远程射击
6. **成长**：采集/合成/攻击/击杀获得经验 → 升级得技能点 → 四大技能树

## 装备与插件

- **装备部位**：头（🪖）、身（🦺）、腿（👖）、鞋（🥾）、背包（🎒），皮革/铁/钢三级
- **穿戴**：打开背包 [E]，**双击**装备穿上；点击已装备部位脱下；护甲减少僵尸伤害（上限 75%）
- **背包容量**：初始 36 格；力量技能【行囊】+4 格/级；背包装备直接扩容（帆布 +6 / 探险 +12）
- **插件**：装备和武器都有插件插槽（熔炉合成，僵尸也会掉落）
  - 点击背包中的插件（标记待安装）→ 再点装备插槽或带插槽的武器完成安装
  - 点击已装插件卸下；右键带插件的背包物品卸下最后一个
  - 武器插件：🗡锋利（+伤害）、⚡迅捷（+攻速）、🎯暴击、🔭瞄准（+远程）
  - 护甲插件：🛡强化（+护甲）、🪶轻羽（+移速）；背包插件：📦扩容（+格数）、🍀掠夺（+掉落）

## 技能树（每类 4-5 个子技能）

- 🧠 **智力**：巧匠（省材料）· 冶金（额外产出）· 博学（+经验）· 蓝图（解锁钢级配方）
- 💪 **力量**：巨力（近战伤害）· 勤工（采集速度）· 健体（生命上限）· 坚韧（减伤）· 行囊（背包格数）
- 🏃 **灵活**：疾行（移速）· 迅击（攻速）· 轻盈（跳跃/坠落）· 闪避（闪避僵尸）
- 👁️ **感知**：鹰眼（暴击）· 神射（远程伤害）· 直觉（危险预警范围）· 拾荒（掉落率）

## 项目结构

```
survival-game/
├── index.html          入口页面 + HUD 布局
├── css/style.css       全部样式
├── lib/three.module.js Three.js r160（本地化）
└── js/
    ├── main.js         主入口：渲染器 / 昼夜循环 / 状态机 / 系统装配
    ├── config.js       全局配置：方块 / 物品 / 配方 / 技能树 / 僵尸参数
    ├── utils.js        工具函数与噪声
    ├── textures.js     程序化像素贴图（无外部资源）
    ├── models.js       人形 / 手持物品 / 掉落物模型
    ├── world.js        体素世界：地形生成 / 区块渲染 / DDA 射线 / AABB 碰撞
    ├── inventory.js    背包与快捷栏
    ├── skills.js       技能系统与属性加成
    ├── crafting.js     合成（工作站检测 / 技能加成）
    ├── player.js       玩家：移动 / 双视角相机 / 生存数值 / 经验升级
    ├── input.js        键鼠输入（指针锁定）
    ├── entities.js     僵尸 AI / 动物 / 掉落物 / 箭矢弹道 / 实体管理
    ├── combat.js       近战 / 采集 / 射击 / 放置与使用
    └── ui.js           HUD / 背包 / 合成 / 技能树 / 死亡界面
```
